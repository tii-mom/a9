## 2. 必须特别确认的经济问题

### 2.1 奖励分配（V3 已确认）

已确认：**纯质押比例分配 + 一次性发放**。

`reward[user] = floor(本轮奖励 × acceptedStake[user] / totalAcceptedStake)`

- 本轮奖励 = 700,000,000（7 亿）。
- 不设贡献积分、不设线性归属、不设额外权重。
- 舍入余数留在奖励金库，不跨轮转移。
- 0 名质押人且轮次通过时奖励无接收人（D-18b 待定：建议销毁）。

### 2.2 质押本金销毁的法律与市场风险

失败时销毁所有本轮质押本金是协议已确认的业务规则（V3 明确保留 100%，不做 50% 回流），风险极高： -
参与者可能损失100%质押本金； - 价格可能被第三方操纵； -
质押者可能提前卖出或拒绝参与； -
该机制可能触及不同司法辖区的金融产品、博彩、促销或消费者保护规则。

必须由专业律师和独立经济风险顾问审查，并在用户签名前充分披露。

### 2.3 失败轮次永久关闭与技术故障

"市场考核失败"永久关闭；"预言机故障"不能伪装成市场失败。

应当区分： - 市场数据有效且12根完整K线中少于8根达标：永久失败并销毁。 -
预言机/链上技术故障：暂停或技术终止，不能销毁本金。 -
无人质押（V3）：**照常启动观察**，按同一 8/12 规则判定；失败销毁本轮奖励，通过按质押比例分配。

## 4. 冻结流程

1.  产品负责人确认经济规则。
2.  经济顾问审查激励和操纵风险。
3.  律师审查发行、质押、本金销毁和奖励机制。
4.  技术负责人确认预言机和 TON 消息架构。
5.  将最终参数生成配置哈希。
6.  在 Testnet 验证配置哈希与运行结果。
7.  审计机构审查同一版本代码和参数。
8.  主网部署并公布参数哈希。

任何部署后变更都必须遵循预先公开的治理与时间锁规则。
