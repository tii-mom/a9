# 14 — 每轮解锁目标价完整表（D-31 决策参考）

**基准**：P0 = $0.001（USD_E8 = 100,000）。若 P0 调整，全表按比例缩放（目标价 = 表中数值 × P0 / 0.001）。
**口径**：第 n 轮目标价 = P0 × m^n（m 为每轮倍数）。若采用 D-28「同档重试」，则这里的 n 是**档位**（tier），不是轮次号。
**判定**：48h / 12 根 4h / 8 根达标。通过率为 σ=300% 年化波动率下的模拟值（见 docs/13）。

## 6. 若 P0 不是 $0.001

所有价格按比例缩放：`目标价 = 表中数值 × (P0 / 0.001)`。

例如 P0 = $0.002 时，1.08× 方案的 R1 = $0.00216、R10 = $0.004318。
